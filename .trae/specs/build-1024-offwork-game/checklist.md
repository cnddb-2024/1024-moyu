# Checklist

- [ ] index.html 为单文件纯 HTML（内联 CSS/JS），双击离线可玩，无外部依赖、无网络请求、无控制台报错
- [ ] 场景包含：主角背影坐在电脑前、显示器滚动代码、桌上蓝色小鱼玩偶、巡逻的 Boss、1024 程序员节装饰
- [ ] 顶部居中显示 1024 秒倒计时，剩余时间分档变色（绿→黄→橙→红），2 的幂里程碑有提示
- [ ] Boss 会行走、随机停留、回头面向主角；危险/安全状态通过朝向、表情/标记、音效清晰可辨
- [ ] Boss 背对时摸鱼可加速倒计时（速率 = 基础值 × 阶段倍率）；Boss 看向主角时摸鱼，反应窗口（约 0.5s）内松手安全、超时被抓
- [ ] 被抓惩罚生效：倒计时回拨（如 +32s）、怀疑度 +1、Boss 训斥气泡、屏幕震动；怀疑度满 3 进入加班失败结局并可重开
- [ ] 全部数值集中在 CONFIG 常量表（基础值 × 倍率系数）；最后 64 秒倍率降低、Boss 回头更频繁且注视更久、有紧张特效
- [ ] 摸鱼时小鱼抖动/形变、手来回搓动、摸鱼进度条抖动增长、周期性 "+N 秒" 漂浮文字
- [ ] 倒计时归零触发全屏烟花粒子 + 胜利结算（加成节省秒数、被抓次数、S/A/B/C 评级、再来一局）
- [ ] 标题页含游戏名《还有1024秒下班》、1024 副标题、玩法说明与开始按钮
- [ ] WebAudio 程序化音效（摸鱼/预警/被抓/烟花）可静音，首次交互后才初始化
- [ ] 鼠标按住、触摸按住、空格按住三种输入均可摸鱼，画面随窗口尺寸自适应
